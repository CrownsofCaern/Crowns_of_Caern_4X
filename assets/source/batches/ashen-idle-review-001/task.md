# Crowns of Cinder: idle, walk and attack animation sheets

You are helping me produce animation sprite sheets for my game. I attach reference strips named `<group>-reference.png` (for example `concord-01-reference.png`). Each strip shows FOUR existing pixel-art creatures, left to right. There are 40 groups in total, listed at the end of this message. I will attach the strips in batches (as many as the chat allows).

For EVERY group you make TWO sheets from the same reference strip:
- **Sheet A**: idle (3 columns) and walk (4 columns), 7 columns.
- **Sheet B**: attack, 6 columns.

## How to work

1. Take the attached reference strips in the order of the group list below, skipping groups whose strip is not attached yet.
2. For each strip, generate Sheet A, then Sheet B, each as ONE image, using that strip as the visual reference and that group's ROWS line from the list.
3. Generate exactly one image per reply. Under the image, write only the group id and the sheet letter (for example `concord-01 A`) so I can file it.
4. Then continue automatically. If you have to stop, wait until I say "next" and carry on where you stopped.
5. If a sheet clearly breaks the rules (wrong number of rows or columns, a creature redesigned, a background drawn), redo it before moving on.
6. When every attached strip is done, say "Batch done" and list what you produced.

## Sheet A specification (idle + walk, identical for every group)

Create a production ANIMATION sprite sheet for the FOUR EXACT existing dark fantasy pixel-art creatures in the attached horizontal reference strip. Preserve original anatomy, equipment, colors, outline weight and identity pixel for pixel wherever the pose allows. Reference left-to-right becomes rows TOP-TO-BOTTOM. Generate EXACTLY SEVEN COLUMNS and FOUR ROWS, 28 separate full-body sprites, on transparent alpha, landscape 1536x1024. No background, shadows, grid, labels or extra figures. Keep wide transparent gutters. Each equal cell 219x256. Body root centered in the cell, the SAME body size, camera and grounded baseline as the reference in every cell. Full weapons, tails and wings fit inside the cell. SAME unit in every column of its row. All face RIGHT. Upper-left lighting, crisp detailed serious pixel art, no redesign, no bright cartoon look.
Columns 1-3: IDLE loop starting from the reference pose: column 1 rest pose matching the reference as closely as possible (inhale: chest and shoulders rise one or two pixels), column 2 weight shift (head turns or tilts a little, weapon or free hand shifts its grip, tail or cloak sways, wings fold and resettle, eyes or flames flicker), column 3 exhale. SMALL, believable motion of individual parts only: feet stay planted, no stepping, no whole-image stretching or bouncing. Flying units hover with a slow wing beat, spectral units drift and billow, constructs hum with tiny mechanical shifts, plants rustle, swarms mill about.
Columns 4-7: WALK cycle in place: first contact pose, first passing/support pose, opposite contact pose, opposite passing/support pose. Animate individual limbs with alternating planted feet and bending knees; quadrupeds move all four legs in a coherent gait, flying units flap wings with a steady body, spectral units billow and float, plants crawl with roots, mechanical artillery rolls its wheels and does not grow legs, swarms move as a coherent cluster. Keep torso shape steady and smooth continuity from the last column back to column 4.

Every frame must be clearly distinct in the appropriate limb, head or weapon positions while keeping exact character continuity. Undead remain frightening, demons monstrous, beasts keep their actual anatomy.

## Sheet B specification (attack, identical for every group)

Create a production ANIMATION sprite sheet for the FOUR EXACT existing dark fantasy pixel-art creatures in the attached horizontal reference strip. Preserve original anatomy, equipment, colors, outline weight and identity pixel for pixel wherever the pose allows. Reference left-to-right becomes rows TOP-TO-BOTTOM. Generate EXACTLY SIX COLUMNS and FOUR ROWS, 24 separate full-body sprites, on transparent alpha, landscape 1536x1024. No background, shadows, grid, labels or extra figures. Keep wide transparent gutters. Each equal cell 256x256. Body root centered in the cell, the SAME body size, camera and grounded baseline as the reference in every cell. Full weapons, tails and wings fit inside the cell. SAME unit in every column of its row. All face RIGHT. Upper-left lighting, crisp detailed serious pixel art, no redesign, no bright cartoon look.
Columns 1-6: one ATTACK toward the RIGHT, six poses with real weight and flow: column 1 anticipation (weight drawn back), column 2 wind-up peak (fully coiled, weapon, claws or jaws raised behind, strongest silhouette), column 3 the MAIN HIT at full contact or release to the right, column 4 and column 5 whatever suits THIS creature best: either a follow-up blow (for example a spearman's second quick thrust, a bite followed by a claw swipe, a cut and backswing) or a powerful follow-through and recoil, column 6 recovery back towards the rest pose. Archers draw the SAME bow and loose a straight arrow in column 3; spellcasters gather and release a modest effect from their existing staff or hand in column 3; artillery fires with barrel recoil in column 3 and settles. Use the SAME weapon and anatomy as the reference; not every creature uses a sword. Avoid gigantic particle effects; preserve anatomy, number of limbs and rigid weapon construction.

Every frame must be clearly distinct in the appropriate limb, head or weapon positions while keeping exact character continuity. Undead remain frightening, demons monstrous, beasts keep their actual anatomy.

The ROWS line for each group says which creature is in which row, top to bottom, in the same left-to-right order as its reference strip.
