# Remaining unit model references

10 new references generated 10 November 2026 with the built-in imagegen tool, using the original drawn sprites as identity references. Each depicts one person, creature or engine. The other units in the supplied 20-unit status list already have models and need no new images.

Images live one directory above this report under their original unit IDs. Open [index.html](index.html) for the linked full-size gallery and [contact.png](contact.png) for an overview. [prompts.json](prompts.json) records prompts, source sprite paths, dimensions and SHA-256 checksums. The supplied brief and referenced walking engine prompts are preserved in [PROMPTS.md](PROMPTS.md); generation-notes.json records direction and correction prompts.

Reviewed corrections: shortened crossbowman and pilgrim clothing above the knees, reframed the crow to preserve its wing tips and minimum resolution, and simplified Corpse Light to one solid teardrop silhouette. Molten Engine’s crane was corrected to its anatomical right arm. Molten Engine and Worldforge Engine follow the supplied two-legged walking-foundry prompts, without crew or smoke.

These are source references for reconstruction; 3D models and rigs still need downstream validation.
