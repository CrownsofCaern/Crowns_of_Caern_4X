# 3D unit references

21 required follow-up references from PROMPTS.md, generated 10 November 2026 using built-in image_gen with the original creature sprites as design references. Optional retries are excluded.

Open index.html for the full-size linked gallery. prompts.json contains the base prompt set, sprite paths, dimensions and SHA-256 hashes. PROMPTS.md preserves the supplied brief. generation-notes.json records final correction prompts.

These are source references for 3D reconstruction, not runtime sprites or validated meshes. All images were visually reviewed for framing and open silhouettes; downstream mesh generation and rigging still need validation. The three shades still require the float animation class described in the brief.
