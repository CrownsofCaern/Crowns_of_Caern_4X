## Keyboard and mouse

| Action | Control |
|---|---|
| Plan a route | Click a tile |
| March | Click the same tile again, or `Space` |
| Cancel a route | Right-click |
| End the day | `E` |
| Hero and army | `H` |
| Next hero | `Tab` |
| Town | `T`; `Tab` switches towns in the town screen |
| Look around | Arrow keys, or click the minimap |
| Centre on your hero | `C` |
| Zoom | Mouse wheel, `+` / `-`, trackpad pinch; `0` resets |
| Scout an enemy | Point at the army and press `S` |
| Save / load | `F5` / `F9` |
| Menu, close a window | `Esc` |

In the battle forecast, `Enter` attacks or continues, `S` scouts and `Esc` withdraws.

To manage an army, pick a stack and then a slot. An empty slot or the same creature takes it; a different creature swaps. `Split` or Shift+click moves part of a stack. In the hero screen, Shift+click hands a piece of equipment to an adjacent hero.

## Touch

| Action | Gesture |
|---|---|
| Plan a route | Tap a tile |
| March | Tap it again |
| Information | Hold |
| Pan the map | Drag |
| Cancel a route | Two-finger tap |
